# Masraweya CMS V6 — All Images

Every public-site visual image now has its own CMS field under Admin → Images.

Includes logo, Home visuals/cards/results/news, About, Academics, School Life cards, Admissions, Contact, Results, News and Gallery images. Background-image cards use CMS background fields too.

No new SQL is required because all values are stored inside the existing `site_content.content` JSONB column.
